# 安全边界

## 第一版

- OKX API Key 只能有 `Read` 权限，不能有 `Trade` 或 `Withdraw` 权限。
- API Key、Secret 和 Passphrase 只保存在 Northflank Secrets 或本地被忽略的 `.env`。
- PostgreSQL 生命周期数据库包含仓位、带单员标识和盈亏快照，数据库与备份不得公开，连接凭据只能放入 Secret。
- `RestClient` 只在服务端创建，浏览器只接收精简 JSON。
- 服务端业务路由只接受 `GET`；只有登录和退出使用 `POST`。
- 第一版代码不得调用 SDK 的下单、平仓、改单、修改杠杆或修改跟单设置方法。
- `/healthz` 不访问 OKX；其他页面和 API 使用独立看板认证。
- 不记录认证请求头、OKX 凭据、签名、预签名字符串或 SDK 完整异常。

`OKX_MOCK=1` 只返回代码内的虚构数据并允许免认证预览，不读取 OKX。生产环境不得设置该变量。

### 看板登录防护

- `AUTH_ALLOWED_COUNTRIES=CN,US` 时，只允许国家代码为中国或美国的请求；其他代码以及缺少代码的请求对外统一表现为普通 `404`，具体拒绝原因只进入内部审计日志。
- 国家代码默认读取可信 Cloudflare 写入的 `CF-IPCountry`。地理限制启用时必须同时设置 `AUTH_TRUST_PROXY=1`，并禁止绕过可信代理直连源站，否则客户端可能伪造请求头。
- `/healthz` 不受地区限制，保证 Northflank 能持续进行容器健康检查。
- 登录页只接受同站 JSON 请求，请求体最多 8 KiB。
- 看板密码至少 16 个字符；生产环境建议使用 24 个以上的随机字符。
- 密码在服务启动时通过 scrypt 派生，比较过程使用固定时间比较；密码不会进入应用日志。
- 每个来源地址连续失败 5 次后锁定 15 分钟；整个账户在同一窗口累计失败 20 次后锁定。
- 同一来源最多同时处理 2 个登录校验，服务最多同时处理 8 个，避免并发密码请求耗尽 CPU。
- 成功登录后签发 256 位随机会话标识，只通过带 `Max-Age`/`Expires`、`HttpOnly`、`SameSite=Strict` 的 Cookie 传递；生产环境增加 `Secure`，以兼容移动 WebView 的持久 Cookie 存储。
- 会话默认有效 30 天（可用 `AUTH_SESSION_TTL_MS` 调整），最多保留 10 个；持久化到 PostgreSQL，因此容器重启后仍可继续登录。退出、过期或更换看板密码会使会话失效。
- 退出登录要求当前会话的 CSRF token。
- 页面返回 CSP、HSTS、点击劫持防护、MIME 嗅探防护和浏览器权限限制等安全响应头。
- 登录成功、失败、锁定和退出只记录事件、时间和来源地址，不记录用户名、密码或会话标识。

生产入口必须使用 HTTPS。部署在 Northflank 等可信反向代理后时设置 `AUTH_TRUST_PROXY=1`，使限流读取代理写入的第一个 `X-Forwarded-For` 地址；不得在允许客户端直接访问服务端口时启用它。

当前限流仍在单实例内存中，不支持多副本共享；数据库服务锁拒绝第二个 OKX 实例同时运行。会话只保存在 `okx_research`，与 A 股的 `stock_watch` 分开；正式环境应分别配置数据库账号与权限。若未来支持多用户、多个副本或细粒度权限，需要进一步设计共享限流、正式身份服务和 MFA。

## 研究阶段

研究模块只产生：

- 趋势状态。
- 候选保本线和滑动止盈线。
- 模拟退出和模拟重新进入。
- 与原始跟单轨迹的对照结果。

研究输出不能直接触发交易。

## 未来执行阶段

真实平仓或再次开单属于新的安全阶段，必须独立批准，并至少满足：

- 使用隔离子账户和专用 Trade Key，监控 Key 继续保持只读。
- 执行服务与读/研究服务分离部署。
- 幂等订单标识和重复下单拦截。
- 单仓、单币种、单日和账户总风险上限。
- 行情过期、网络异常、交易所异常和状态不一致时拒绝执行。
- 紧急停止、完整审计日志和人工接管能力。
- 模拟与小额阶段达到事先定义的验收条件。

## 已实现的独立模拟策略服务

`src/signals` 与上文的只读 OKX 看板分离，当前授权范围仅含 `paper`（真实公开行情、虚拟成交）和 `okx-demo`（OKX 模拟盘订单）。仅该独立适配器可以调用模拟盘下单接口，强制 SDK `demoTrading=true` 和 `x-simulated-trading: 1`；不存在实盘执行模式，不复用 `OKX_API_*`。浏览器与 Discord 工具不得指定交易模式、订单数量或扩大服务端风险上限。

通过 `Dockerfile.signals` 单独部署，配置独立数据库与登录凭据；`SIGNAL_API_TOKEN` 只授予登记、查询和控制模拟方向任务的权限。模拟盘专用密钥仅注入此服务，不注入 ZeroClaw。已有 ZeroClaw 启动脚本的环境继承问题仍需单独部署处理，不能通过把模拟密钥加入同一容器来绕过隔离。

资金费目前为每个开始的 8 小时窗口保守预留，账本净收益是含估算费用的研究结果。保护在服务轮询报价时执行，尚未映射为交易所原生条件单；服务断线期间无法更新或执行保护，恢复后按实际可得报价处理。模拟结果不能表述为保证保本或回测盈利证明。
