# 项目方向与验证顺序

日期：2026-09-16。本文是结合已确认目标、代码和本地运行状态形成的开发建议，不是收益结论。后续实施优先级以本文为准，旧研究文档中的参数仍属于待验证候选。

用户后续明确选择“提供方向 → ZeroClaw 根据策略与网络资料分析 → 模拟盘自动执行 → 持续复盘改进”。因此，固定版本的模拟观察与影子对照研究并行推进；不要求先完成长期回测才允许每个已明确提供的方向开始模拟。每轮仍受 100 USDT 保证金、3 倍逐仓和现有风险约束；只在收到真实方向后登记，具体入口见 [自动模拟观察](signal-discord.md#用户方向--网络研究--自动模拟观察)。2026-09-17 已新增本地 Discord 群聊截图入口；云端持续运行部署仍待接入。2026-09-22 增加默认关闭的 AI 定时扫描入口，机器扫描样本必须单独归类，不能混入用户方向验证集，见 [AI 定时扫描入口](signal-discord.md#ai-定时扫描入口可选默认关闭)。

## 核心定位

围绕外部提供的交易方向，建立可验证的持仓管理系统：记录方向来源，按固定规则生成入场候选和执行保护，量化保本、追踪与重复入场的独立贡献。第一阶段的核心问题是：同样的首次入场，系统是否改善整个方向任务的扣费净结果和风险。

用户的长期体验目标仍是：提供一个方向后，系统持续观察、管理仓位、解释每次动作，并在条件合适时研究再次入场。实现顺序由证据决定，不能因为功能能够运行，就认定该功能应该成为默认交易行为。

## 目前确实知道什么

| 证据 | 能支持的结论 | 尚不能支持的结论 |
| --- | --- | --- |
| 最小规模 OKX 模拟开仓、reduceOnly 平仓成功 | 账户和基本执行接口可用 | 持续策略有正期望、实盘成交效果相同 |
| 状态机、订单意图持久化、账户对账及重启测试通过 | 有继续研究所需的执行骨架 | 断线保护、长期运行和所有交易所异常均已验证 |
| 本地服务健康，核对时 0 方向任务、0 策略持仓 | 服务正在运行，尚无活动研究样本 | 已经持续积累策略收益数据 |
| ZeroClaw 读取真实行情，规则和结构化结论经核对 | 解释链路能引用实际工具证据 | 模型有预测优势或能选择盈利策略 |
| 当前任务、轮次、事件、报价和 K 线可落盘 | 可扩展为可复现的实验底座 | 已有来源质量统计、完整反事实轨迹或真实资金费流水 |

当前行情落盘跟随活动任务；零任务期间不会因看板健康就自动生成可供策略比较的观测数据。旧跟单入口仍受 copy 子仓位权限／精确归属验证制约，不应让这个依赖阻塞独立方向研究。

## 必须分开验证的三个问题

### 1. 输入方向是否有价值

来自截图或高手的方向不能直接视为有效信号。截图可能是历史战绩、迟到的持仓展示或筛选后的赢家。原作者开仓价也不是系统收到消息时可成交的价格。`ai:auto:` 来源是可选机器定时扫描，属于另一类样本，不得进入“外部方向是否有价值”的主验证集。

原始消息接收时即记录来源、时间、合约、方向、是否历史内容及解析不确定性；重复消息合并；未成交、失效、含糊和亏损记录全部保留。后续比较外部方向与同时间的纯规则基线，才判断来源的增量价值。可以先用合成方向做机械验证，但不得据此评价真实来源。

### 2. 退出管理是否改善交易

早保本、紧追踪可能减少浮盈回吐，也可能提前截断大趋势，使长期净收益降低。主指标先采用每个原始方向任务的扣费净收益差，辅以任务回撤、尾部亏损、盈利回吐及提前退出的机会损失；胜率和保证金回报率不作为主要结论。

比较须锁定同样的首笔成交时间、价格、数量、初始风险和行情。若同时换入场与出场，无法识别是哪一部分带来变化。

### 3. 再入场是否值得增加成本

上一轮盈利不说明下一轮有优势。按所有原始方向任务评价开启／关闭重入的差异，包含未触发重入的任务，不能只展示符合条件的赢家。当前自动模拟入口运行最多三轮的候选完整策略，允许满足既定条件后的同方向重入，用于积累执行证据；其净增益仍须由关闭／开启重入的影子对照验证，不能把功能可用当成有效性结论。

## 首轮对照设计：四组逐项增加规则

| 组别 | 规则 | 与前一组比较回答什么 |
| --- | --- | --- |
| A 基线 | 初始止损＋统一最长持仓／强制退出 | 建立无主动盈利保护的参考 |
| B 成本保本 | A＋达到既定条件后保护成本；不追踪、不重入 | 保本本身的收益和代价 |
| C 保本追踪 | B＋单向追踪；不重入 | 追踪增加多少收益、截断多少趋势 |
| D 完整观察 | C＋同方向冷却重入；最多三轮 | 重入对整个方向任务的净增益与额外风险 |

第一阶段共享首笔入场，对照轨迹在虚拟账本中独立推进，不各自向同一个净持仓模拟账户下单。模拟账户用于验证一个固定执行配置的订单行为；实验收益主要由同源行情的影子轨迹比较。之后另做组合容量测试，避免实验组抢占额度改变对照样本。

原作者平仓可以作为额外基线，前提是有当时可靠的记录，不能从截图补造完整轨迹。当前开发中的三组 OHLC 回放用于检查计算、交易成本和状态机；还需要补 B 组及共享首次成交对照，才能用于逐项归因。

## 数据与研究方法

- `ai:auto:` 机器扫描样本与真实用户方向分开分组统计，不合并来源质量结论；样本不足时继续标记证据不足。
- 自动开单默认开放 ETH-USDT-SWAP 与 BTC-USDT-SWAP；研究样本仍先以 ETH 验证机制，再用 BTC 做分阶段外部验证。保持每轮保证金最多 100 USDT、默认 3 倍逐仓，符合现有用户预算。
- 保存真实可获得报价和接收时间，逐步增加独立于执行的公共行情采集。优先补可靠数据与异常区间，暂不为大量指标扩大采集范围。
- 15 分钟 OHLC 回放只作初筛。O-H-L-C 与 O-L-H-C 是两种假设路径，并非真实轨迹，也不是收益上下界证明。对路径敏感的结论必须用更细行情或向前采集的数据复查。
- 按时间冻结开发样本与后续验证样本；后续样本开始前锁定策略、费用、参数和主指标。记录所有尝试，避免只保留最好参数。
- 回测窗口可逐步覆盖数月的不同行情；最近七天只适合链路验证。真实方向任务从接收时开始观察，历史方向不足时明确缺失，不批量创造所谓真实信号。
- 费用先按现有保守口径记录，并做提高滑点／点差的敏感性比较；随后接入真实模拟成交费用和适用的资金费数据。估算成本与实际成本分栏。
- 同一方向的多轮、同一时段的相关信号和多空假设不是独立样本。统计以方向事件为单位，并按日期／来源分组检验；独立试验盈亏之和不当成可实现的组合收益。

## 100 USDT 预算意味着什么

100 USDT 保证金、3 倍杠杆约对应 300 USDT 名义金额。按当前默认单边手续费 5 bps、滑点 2 bps 估算，一次往返约 0.30 USDT 手续费和 0.12 USDT 滑点，尚未计点差与资金费。标的有利移动 0.4% 的毛收益约 1.20 USDT；上述两项成本已占约 35%。频繁小额保护退出和重入可能让成本吃掉优势。

2026-09-16T14:18:35Z 的 ETH 假设仓位约 299 USDT，状态机估算计划风险约 2.93 USDT，远低于 25 USDT 硬上限。这不是成交或实际损失。100 USDT 是资金分配上限，25 USDT 是风险上限；两者都不是必须用满的目标。分析需同时展示 USDT 净结果与按本轮实际初始风险归一化的结果。

## ZeroClaw 的优先职责

1. 整理方向来源：准确合约、方向、发布时间／接收时间、事实与推断、歧义和重复来源。
2. 基于工具解释：为何未入场、为何退出、保护价格如何计算、哪些数据缺失。
3. 复盘与异常归类：损失主要来自方向、入场、追踪过紧、成本还是执行中断；给出可验证的新假设。
4. 管理实验记录：指出缺失证据与相互矛盾的结论，保留规则和提示词版本。

五秒行情判断和订单保护由确定性程序承担。模型生成的新规则先作为独立实验版本验证，不即时改变正在执行的参数。以后若要研究模型的行情分类，应预先保存标签，再验证标签带来的增量，不能事后解释赢家。

## 后续开发优先级及完成条件

| 优先级 | 实施 | 可检查的完成条件 |
| --- | --- | --- |
| P0 | 先打通明确方向的受限自动模拟入口，再接通实际使用的消息渠道 | 本地入口已有意图、证据和额度校验；真实消息去重、研究样例隔离、登记回执可查；云端 Discord 仍待接入 |
| P0 | 统一实验口径，冻结候选规则；补来源与决策时间记录 | 同一事件可重放；拒绝／未成交记录不遗漏；参数版本可追溯 |
| P0 | 完成四组共享首笔成交的影子对照 | 每组首笔一致；保本、追踪、重入增量可分别计算；无未来数据 |
| P0 | 改造研究结果页 | 每个方向一行，显示 A/B/C/D 净结果、费用、回撤、重入贡献与数据质量 |
| P1 | 持续采集与模拟执行并行观察 | 行情缺口、订单不确定、重启恢复有记录；影子结果与实际成交偏差可解释 |
| P1 | 分来源、行情阶段做后续样本验证 | 规则冻结，报告成对差值及不确定性，能说明优势是否集中于少数事件 |
| P2 | 根据对照决定是否保留重入，扩大 BTC 验证样本并完善 Discord 图片解析 | 对应功能有独立增益或明确使用价值，不为增加交易数量而开启 |

前两周用于完成实验底座并开始向前采样，不把两周到期当作盈利验证完成。首个正式评审可采用至少八周、约一百个去重方向事件作为排期目标；低频输入则延长，不能人为增加信号凑数。重入事件不足时继续标记证据不足。这些数量不是显著性保证，还须看效应大小、依赖关系和置信区间。

## 继续、简化或停止的依据

- 成本保本或追踪在冻结的后续样本中提高净收益，同时没有不可接受的风险恶化：继续扩大验证。
- 净收益下降但回撤改善：明确展示取舍，先量化愿意牺牲多少收益，不事后换目标宣称胜出。
- 重入没有净增益或主要增加费用、尾部亏损：默认关闭重入，保留观察与复盘能力。
- 结果依赖某一参数、单段行情或 OHLC 顺序：证据不足，先改进验证，暂停新增策略复杂度。
- 来源不能胜过同时间的简单规则：降低该来源权重，重新评估方向输入的价值；不能靠退出规则承诺修复任意错误方向。

当前暂缓多币种铺开、指标堆叠、自动截图下单和实盘扩展。需要长时间稳定采样时再按采集目标安排部署。实盘执行另有交易所原生保护、资金费、故障恢复和容量要求，不属于本次路线推进的默认步骤。
